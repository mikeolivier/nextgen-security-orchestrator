


# NextGen Security Orchestrator

## Overview

NextGen Security Orchestrator is an enterprise cloud security platform built on AWS using Terraform and Python.

The platform provides:

- Identity and Access Management (IAM)
- Threat Detection (GuardDuty)
- Compliance Monitoring (AWS Config)
- Event Routing (EventBridge)
- Incident Orchestration (AWS Lambda)
- Notification (Amazon SNS)
- Encryption (AWS KMS)
- Secrets Management
- Security Hub Integration
- CloudTrail Logging
